# Round-Robin-1

Планировщик процессов Round Robin. Фронтенд на HTML и JavaScript, бэкенд на Python (без сторонних библиотек).

## Запуск

1. Откройте терминал в папке проекта.
2. Введите: python main.py
3. Откройте в браузере http://127.0.0.1:8001

## Файлы

- main.py: сервер, считает расписание Round Robin
- index.html: страница с формой, диаграммой Ганта и таблицей метрик
